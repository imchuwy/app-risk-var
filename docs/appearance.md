# Appearance

The header uses the transparent Shore Wash banner in both themes. The dark theme maps its wave to ivory and keeps the coral sun. CSS preserves the banner's original aspect ratio at every width. The square Open Water and Nightfall icons are used for the light and dark favicons.

The artwork, fonts and theme tokens come from the [portfolio design kit](https://github.com/imchuwy/ux-template). See the [font licenses](../public/oc/assets/fonts/licenses).
